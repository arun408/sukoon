# 🌿 Sukoon — A Serene Spa & Wellness Experience

> **"Rest, restored. Slow rituals, warm stones, and quiet rooms."**

## 📖 Overview

**Sukoon** (meaning *a deep, settled calm*) is a luxury web experience designed for a holistic spa and wellness sanctuary. The platform reflects tranquility and mindful living through immersive visuals and unhurried interactions. It showcases Ayurvedic and Swedish therapies, quiet retreat spaces, and personalized booking features—offering visitors a peaceful digital escape before they step into the sanctuary.

---

## ✨ Features & Interactive Elements

* **Interactive Visuals:** Scroll-triggered lotus blooming animations and immersive ambient design.
* **Conversational Booking Assistant:** Integrated AI voice/text chatbot named **Anaya** to guide visitors and assist with booking quiet hours.
* **Responsive 3D Space:** Dynamic 3D depth and parallax elements providing an authentic retro-modern spatial experience.

---

## 🛠️ Tech Stack & Architecture

This project is built purely using modern web standards without heavy external frameworks:

* **HTML5:** Semantic structure optimizing layout and accessibility.
* **CSS3 & CSS 3D Transforms:** Advanced styling, smooth custom transitions, responsive grids, and 3D spatial transformations.
* **Vanilla JavaScript (ES6+):** Core application logic, smooth UI interactions, and state management.
* **Three.js:** WebGL-driven 3D rendering for smooth ambient animations and graphics.
* **Web Speech API:** Voice recognition and synthesis powering the interactive chatbot **Anaya**.
